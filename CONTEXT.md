# Atlas Domain Context

## Terms

**Atlas Taxonomy**: Canonical vocabulary for existing atlas categories used in display, grouping, and route category decisions.

**Source Kind**: The record-level kind of an atlas source, currently artifact, inscription, manuscript, text, collection, or archive.

**Entity Type**: The structural identity type of an atlas entity, such as agent, place, event, text work, or physical object.

**Display Category**: Human-facing category derived from entity type plus subtype fields like agent kind, place kind, or event kind.

**Evidence Layer**: A user-visible grouping of evidence overlays in text or image review.

**Personal Tag**: A user-authored label on sources; not part of Atlas Taxonomy.

## Non-Concepts

**Theme** and **topic** are not first-class atlas concepts yet.
